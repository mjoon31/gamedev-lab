# 체력이 0 아래로 내려가지 않게

## 문제

학습일: 2026-11-16

초기 체력 80인 캐릭터에 피해를 적용합니다. 체력은 0 아래로 내려가지 않으며 음수 피해는 무시합니다.

- Health는 초기 80을 읽을 수 있는 프로퍼티입니다.
- ApplyDamage(int amount)는 양수 피해만 적용합니다.
- 체력은 최소 0이며, 호출 사이에 상태를 유지합니다.

## 내 풀이 코드

```csharp
using System;

public class HealthPractice
{
    private int health = 80;
    public int Health => health;

    public void ApplyDamage(int amount)
    {
        // 양수 피해만 적용하고 하한을 지키세요.
        if (amount <= 0)
            return;
            
        health -= amount;
        health = Math.Max(0, health);
    }
}

```
