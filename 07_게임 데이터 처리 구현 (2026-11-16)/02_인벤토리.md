# 고정 슬롯에 아이템 쌓기

## 문제

학습일: 2026-11-16

4칸 인벤토리에 나무를 넣습니다. 슬롯마다 최대 5개이며 앞 슬롯부터 채웁니다. 같은 인스턴스의 기존 수량을 유지하고 넣지 못한 수량을 반환하세요.

- 새 인스턴스의 4개 슬롯은 모두 비어 있습니다.
- AddWood(int amount)는 앞 슬롯부터 채우고 남은 수량을 반환합니다.
- GetCount(int index)는 해당 슬롯의 수량을 반환합니다.
- 0 또는 음수 요청은 상태를 바꾸지 않고 0을 반환합니다.

## 내 풀이 코드

```csharp
using System;

public class SlotPractice
{
    private readonly int[] counts = new int[4];
    public int GetCount(int index) => counts[index];

    public int AddWood(int amount)
    {
        // 앞 슬롯부터 최대 5개씩 채우세요.
        if (amount <= 0)
            return 0;
            
        int maxCount = 5;
        
        for (int i = 0; i < counts.Length; i++)
        {
            int available = 5 - counts[i];
            int addCount = Math.Min(available, amount);
            counts[i] += addCount;
            amount -= addCount;
        }
        
        return amount;
    }
}

```
