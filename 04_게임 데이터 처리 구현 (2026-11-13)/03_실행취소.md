# 가장 최근 행동부터 되돌리기

## 문제

학습일: 2026-11-13

0 이상 행동 ID를 쌓고 가장 최근 행동부터 꺼내는 실행 취소 기록을 만드세요.

- Push(int id)는 0 이상 ID만 저장합니다.
- Undo()는 가장 최근 ID를 제거하고 반환합니다.
- 비어 있으면 -1이며 인스턴스별 기록은 독립적입니다.

## 내 풀이 코드

```csharp
using System.Collections.Generic;

public class StackPractice
{
    List<int> stackList = new List<int>();
    
    public void Push(int id)
    {
        if (id < 0)
            return;
            
        stackList.Add(id);
    }

    public int Undo()
    {
        if (stackList.Count == 0)
            return -1;
            
        int lastIndex = stackList.Count - 1;
        int lastValue = stackList[lastIndex];
        
        stackList.RemoveAt(lastIndex);
        return lastValue;
    }
}

```
