# 유효한 획득 점수 합산하기

## 문제

학습일: 2026-11-13

획득 점수 배열에서 양수 점수만 합산하세요. 테스트 입력의 각 값은 -1,000~1,000, 배열 길이는 1,000 이하입니다.

- Calculate(int[] points)는 양수만 더한 값을 반환합니다.
- 0과 음수는 합산하지 않습니다.
- null·빈 배열이면 0이며 입력 배열을 바꾸지 않습니다.

## 내 풀이 코드

```csharp
public class ScorePractice
{
    public int Calculate(int[] points)
    {
        if (points == null)
            return 0;
            
        int sum = 0;
            
        for (int i = 0; i < points.Length; i++)
        {
            if (points[i] > 0)
            {
                sum += points[i];
            }
        }
        
       return sum;
    }
}

```
