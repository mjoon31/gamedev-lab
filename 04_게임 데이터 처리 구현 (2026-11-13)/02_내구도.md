# 최대 내구도까지만 수리하기

## 문제

학습일: 2026-11-13

현재 내구도 40인 도구를 최대 100까지만 수리하고 실제로 증가한 양을 반환하세요.

- Durability는 초기 40이며 최대 100입니다.
- Repair(int amount)는 양수 요청만 처리합니다.
- 반환값은 요청량이 아니라 실제 증가한 양입니다. 0·음수 요청은 0을 반환합니다.

## 내 풀이 코드

```csharp
using System;

public class DurabilityPractice
{
    private int durability = 40;
    public int Durability => durability;
    private int maxdurability = 100;

    public int Repair(int amount)
    {
        if (amount <= 0)
            return 0;
            
        if (durability == maxdurability)
            return 0;
            
        int previousDurability = durability;
        durability = Math.Clamp(durability + amount, 0, maxdurability); 
        
        return durability - previousDurability;
    }
}

```
