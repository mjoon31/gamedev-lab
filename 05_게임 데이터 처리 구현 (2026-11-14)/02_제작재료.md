# 제작 재료가 충분한지 확인하기

## 문제

학습일: 2026-11-14

제작에는 나무 3개와 돌 2개가 필요합니다. 보유량을 변경하지 않고 제작 가능 여부만 판단하세요.

- CanCraft(int wood, int stone)는 나무 3 이상이면서 돌 2 이상이면 true입니다.
- 음수 보유량은 false입니다.
- 한 재료만 충분하면 제작할 수 없습니다.

## 내 풀이 코드

```csharp
public class MaterialPractice
{
    public bool CanCraft(int wood, int stone)
    {
        int woodCost = 3;
        int stoneCost = 2;
        
        if (wood < 0 || stone < 0)
            return false;
        
        if (wood >= woodCost && stone >= stoneCost)
        {
            return true;
        }
        
        return false;
    }
}

```
