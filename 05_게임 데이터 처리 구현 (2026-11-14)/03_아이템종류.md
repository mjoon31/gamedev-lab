# 중복 없는 아이템 종류 세기

## 문제

학습일: 2026-11-14

아이템 ID 배열에 등장하는 서로 다른 ID의 개수를 구하세요. 모든 정수 ID를 값으로 취급합니다.

- CountUnique(int[] ids)는 서로 다른 값의 개수를 반환합니다.
- null 또는 빈 배열이면 0입니다.
- 같은 ID가 여러 번 나와도 한 종류로 셉니다.

## 내 풀이 코드

```csharp
using System.Collections.Generic;

public class UniquePractice
{
    HashSet<int> resultSet = new HashSet<int>();
    
    public int CountUnique(int[] ids)
    {
        if (ids == null || ids.Length == 0)
            return 0;
            
        for (int i = 0; i < ids.Length; i++)
        {
            resultSet.Add(ids[i]);
        }
        
        return resultSet.Count;
    }
}

```
