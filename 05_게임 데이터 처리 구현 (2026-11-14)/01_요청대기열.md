# 상호작용 요청을 순서대로 처리하기

## 문제

학습일: 2026-11-14

0 이상 요청 ID를 넣고 먼저 들어온 순서대로 꺼내는 작은 대기열을 만드세요.

- Enqueue(int id)는 0 이상 ID만 저장합니다.
- TakeNext()는 가장 오래된 요청을 제거하고 반환합니다.
- 비어 있으면 -1이며 인스턴스별 대기열은 독립적입니다.

## 내 풀이 코드

```csharp
using System.Collections.Generic;

public class QueuePractice
{
    List<int> queueList = new List<int>();
    
    public void Enqueue(int id)
    {
        if (id < 0)
            return;
            
        queueList.Add(id);
    }

    public int TakeNext()
    {
        if (queueList.Count == 0)
            return -1;
            
        int removeIndex = queueList.Count - queueList.Count;
        int removeValue = queueList[removeIndex];
        queueList.RemoveAt(removeIndex);
        return removeValue;
    }
}

```
