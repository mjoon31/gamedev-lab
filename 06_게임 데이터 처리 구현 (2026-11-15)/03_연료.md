# 연료가 충분할 때만 사용하기

## 문제

학습일: 2026-11-15

초기 연료 10에서 요청한 양을 소비합니다. 실패한 요청은 연료를 바꾸면 안 됩니다.

- Fuel은 현재 연료이며 초기값은 10입니다.
- TryConsume(int amount)는 0보다 크고 남은 연료 이하인 요청만 성공합니다.
- 성공하면 연료를 줄이고 true, 실패하면 변경 없이 false를 반환합니다.

## 내 풀이 코드

```csharp
public class FuelPractice
{
    private int fuel = 10;
    public int Fuel => fuel;

    public bool TryConsume(int amount)
    {
        if (amount <= 0)
            return false;
            
        if (amount <= fuel)
        {
            fuel -= amount;
            return true;
        }
        else
            return false;
    }
}

```
