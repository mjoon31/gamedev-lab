# 가장 가까운 자원 고르기

## 문제

학습일: 2026-11-15

거리 배열에서 가장 가까운 유효 대상의 인덱스를 반환합니다. 음수 거리는 무효이며 같은 거리에서는 앞 인덱스를 고릅니다.

- FindNearest(int[] distances)는 가장 작은 0 이상 거리의 인덱스를 반환합니다.
- null·빈 배열·유효 대상 없음은 -1입니다.
- 같은 최단 거리라면 가장 앞 인덱스입니다.

## 내 풀이 코드

```csharp
public class NearestPractice
{
    public int FindNearest(int[] distances)
    {
        if (distances == null)
            return -1;
            
        int minimum = -1;
            
        for(int i = 0; i < distances.Length; i++)
        {
            if (distances[i] >= 0)
                {
                    if (minimum < 0)
                    {
                        minimum = i;
                    }
                    else if (distances[i] < distances[minimum])
                    {
                        minimum = i;
                    }
                }
        }    
          
        return minimum;
    }
}

```
