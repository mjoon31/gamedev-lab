# 2초 쿨타임 만들기

## 문제

학습일: 2026-11-15

첫 사용은 시각 0부터 가능하고, 성공한 사용 후 2초가 지나야 다시 사용할 수 있습니다. Unity 없이 전달받은 시각으로 연습합니다.

- TryUse(float now)는 현재 시각을 받습니다.
- 음수 시각은 거부합니다. 처음 허용 시각은 0이며 테스트는 유한한 시각값을 사용합니다.
- 성공하면 다음 허용 시각을 now + 2로 정하고 true를 반환합니다.
- 거부된 요청은 다음 허용 시각을 바꾸지 않습니다.

## 내 풀이 코드

```csharp
public class CooldownPractice
{
    private float nextUseTime = 0f;

    public bool TryUse(float now)
    {
        if (now < 0f)
            return false;
            
        if (now >= nextUseTime)
            {
                nextUseTime = now + 2f;
                return true;
            }
        else
            return false;
    }
}

```
