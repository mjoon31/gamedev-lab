# 시간 누적과 작업 완료 · 이벤트와 수명 관리 (2026-11-16)

## 문제

학습일: 2026-11-19

수동으로 시간을 전달하는 타이머 클래스를 만듭니다. 예를 들어 Tick(0.5)는 0.5초가 지났다는 입력입니다. Unity Update나 코루틴 없이 시간 계산·일시정지·완료 이벤트를 단계별로 익힙니다.

- 새 인스턴스는 Remaining=0, IsRunning=false입니다. 입력 시간은 유한한 double이며 단위는 초입니다.
- Start(seconds)는 남은 시간을 Math.Max(0, seconds)로 설정합니다. 남은 시간이 양수일 때만 IsRunning=true입니다. 진행 중에 다시 호출하면 마지막 요청 시간으로 재시작합니다.
- Tick(deltaSeconds)은 실행 중이고 deltaSeconds>0일 때만 남은 시간을 감소시킵니다. 0 아래로 내려가지 않으며 완료하면 IsRunning=false입니다. 정지 상태·0·음수 Tick은 무시합니다.
- 실제 시간 대기, Thread.Sleep, UnityEngine, Coroutine을 사용하지 않습니다. Tick으로 전달받은 시간만 계산합니다.
- Pause는 실행 중일 때만 IsPaused=true로 만듭니다. 일시정지 중에도 IsRunning=true이며 Tick은 무시합니다. Resume은 실행 중 일시정지를 해제합니다.
- Cancel은 Remaining=0, IsRunning=false, IsPaused=false로 초기화합니다. Start도 항상 IsPaused=false로 재시작합니다. 완료 상태·취소 상태에서 Pause/Resume은 아무 변화가 없습니다.
- 양수 시간으로 시작한 작업이 Tick에 의해 처음 완료될 때 CompletionCount를 1 늘리고 Finished를 한 번 발행합니다. 반복 Tick, Cancel, Start(0 이하)는 완료로 세지 않습니다.
- 완료 상태와 CompletionCount를 먼저 반영한 뒤 Finished를 호출합니다. 구독자가 Finished 안에서 Start를 다시 호출해도 그 새 작업의 상태를 덮어쓰지 않습니다. Finished 구독 해제도 정상 동작해야 합니다.

## 내 풀이 코드

```csharp
using System;

public class DailyPractice
{
    public double Remaining { get; private set; }

    public bool IsRunning { get; private set; }
    public void Start(double seconds) 
    {
        if (IsPaused)
            IsPaused = false;
            
        Remaining = Math.Max(0, seconds);
        IsRunning = Remaining > 0;
        
    }

    public void Tick(double deltaSeconds) 
    {
        if (!IsRunning || deltaSeconds <= 0)
            return;
            
        if (IsPaused)
            return;
            
        Remaining = Math.Max(0, Remaining - deltaSeconds);
        
        if (Remaining == 0)
        {
            IsRunning = false;
            CompletionCount++;
            Finished?.Invoke();
        }
    }

    public bool IsPaused { get; private set; }

    public void Pause() 
    {
        if (IsRunning)
            IsPaused = true;
    }

    public void Resume() 
    {
        if (IsPaused )
            IsPaused = false;
    }

    public void Cancel() 
    {
        Remaining = 0;
        IsRunning = false;
        IsPaused = false;
    }

    public int CompletionCount { get; private set; }

    public event Action Finished;
}

```
