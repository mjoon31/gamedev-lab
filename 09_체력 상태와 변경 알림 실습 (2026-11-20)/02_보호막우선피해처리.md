# 보호막 우선 피해 처리 (2026-11-20)

## 문제

학습일: 2026-11-20

보호막 우선 피해 처리 기능을 구현합니다. 객체에 유지되는 상태를 바꾸고 변경 시점과 알림 횟수를 확인합니다.

- DailyPractice 인스턴스의 초기 Health는 100입니다.
- 0 이하 피해는 무시하고 Health는 0 미만으로 내려가지 않습니다.
- 서로 다른 인스턴스의 상태는 독립적입니다.
- 입력 피해 범위는 -1000~1000입니다.
- 초기 Shield는 50이며 피해를 먼저 흡수합니다. ApplyDamage(int amount)는 실제로 감소한 체력만 int로 반환합니다.

## 내 풀이 코드

```csharp
using System;

public class DailyPractice
{
    public int Health => health;
    public int Shield => shield;
    private int health = 100;
    private int shield = 50;

    public int ApplyDamage(int amount)
    {
        amount = Math.Clamp(amount, -1000, 1000);
        
        if (amount <= 0)
            return 0;
            
        int damage = Math.Max(0, amount - shield);
        
        shield = Math.Max(0, shield - amount);
        
        if (shield > 0 || damage <= 0)
            return 0;
        
        int previousHealth = health;
        
        health = Math.Max(0, health - damage);
        
        return previousHealth - health;
    }
}

```
