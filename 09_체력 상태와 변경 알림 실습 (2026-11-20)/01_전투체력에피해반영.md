# 전투 체력에 피해 반영 (2026-11-20)

## 문제

학습일: 2026-11-20

전투 체력에 피해 반영 기능을 구현합니다. 객체에 유지되는 상태를 바꾸고 변경 시점과 알림 횟수를 확인합니다.

- DailyPractice 인스턴스의 초기 Health는 100입니다.
- 0 이하 피해는 무시하고 Health는 0 미만으로 내려가지 않습니다.
- 서로 다른 인스턴스의 상태는 독립적입니다.
- 입력 피해 범위는 -1000~1000입니다.
- ApplyDamage(int amount)는 void 메서드입니다.

## 내 풀이 코드

```csharp
using System;

public class DailyPractice
{
    public int Health => health;
    private int health = 100;

    public void ApplyDamage(int amount)
    {
        if (amount <= 0)
            return;
            
        health = Math.Max(0, health - amount);
        
    }
}

```
